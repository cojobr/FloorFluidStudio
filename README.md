# Floor Fluid Studio — public build

Build estático compartilhável do Floor Fluid Studio.

- Aplicação: <https://cojobr.github.io/FloorFluidStudio/>
- Código-fonte: repositório privado
- Indexação: bloqueada por `robots.txt` e pelas diretivas `noindex, nofollow`

Este repositório contém somente os arquivos compilados necessários para executar o visualizador no navegador.

O aplicativo inicia em **Só fluido**, sem imagens embarcadas. Para usar imagens próprias, abra **Cenas → Imagens + fluido** e carregue arquivos locais. As imagens ficam somente na sessão do navegador e não são enviadas ao site.
